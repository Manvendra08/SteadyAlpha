# SteadyAlpha — Project Context

## Purpose
SteadyAlpha is a staged market-intelligence and trading simulation system designed for positional trading (Daily/Weekly trends). It aims to evolve from a trusted intelligence console to a research-grade evaluation platform, avoiding premature complexity.

## Core Value
1. **Trusted Intelligence:** Reliable market-state assessment and candidate review.
2. **Deterministic Replay:** Traceable signals and historical reconstruction.
3. **Honest Simulation:** Paper trading with realistic assumptions and no execution illusions.
4. **Evidence-Based Evolution:** Each new layer (ML, Automation) must earn its place through explicit performance gates.

## Target Audience
Individual traders/operators seeking a reliable, data-driven decision-support system.

## Status: Phase 0 Complete
- Phase 0: Foundation and Operating Model completed. Basic infrastructure, run registration schema, and Next.js shell implemented.
- Current active stage: Stage 1 (Data Reliability Layer).

## Technical Stack
- **Compute:** GitHub Actions (Python pipeline)
- **Storage/Realtime:** Supabase (PostgreSQL)
- **UI:** Vercel (Next.js/React or similar)
- **Logic:** Custom Python engines for Regime, Flows, Leadership, and Risk.
